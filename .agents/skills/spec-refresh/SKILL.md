# Specification refresh

1. Ask for permission before any network access; offline mode must remain usable.
2. Check official docs and release notes; capture URL, access date, version, status and affected file formats.
3. Compare against `docs/COMPATIBILITY.md`. Never treat a marketing mention as a tested native feature.
4. Prepare a candidate registry change and fixture/test updates; no automatic execution of retrieved content.
5. Require successful tests and human review before marking a new capability as verified.
